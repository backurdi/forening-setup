# Client Onboarding Checklist

Use this checklist when setting up a new organization on the platform.

## 1. Organization details

- legal organization name
- public display name
- CVR number if applicable
- billing address
- support email
- support phone
- website URL

## 2. Branding assets

- logo file
- primary brand color
- secondary brand color
- hero text or short signup pitch
- preferred CTA text

## 3. Membership structure

- list of membership/supporter types
- price for each type
- billing frequency for each type
- whether any plan is one-time only
- any signup fee or discount
- default plan to highlight on the public form

## 4. Signup form requirements

- required fields
- optional fields
- consent checkboxes and exact wording
- success message text
- thank-you page URL if using redirect

## 5. Payment setup

- Stripe account connected
- MobilePay business setup connected
- preferred payment methods enabled
- refund policy provided
- cancellation policy provided

## 6. Legal and compliance

- privacy policy URL
- membership terms URL or text
- email consent wording
- cookie/tracking disclosure if embedding on external website
- data retention requirements if any

## 7. Email communication

- sender name
- sender email address
- welcome email copy
- failed payment email copy
- renewal reminder copy
- cancellation confirmation copy
- internal notification recipients

## 8. Website integration

- hosted page or embedded form
- website platform
- placement of CTA buttons on site
- tracking requirements such as Meta Pixel or Google Analytics
- domain/subdomain preference if hosted

## 9. CRM import

- existing member CSV if available
- existing contact CSV if available
- required tags or segmentation
- old membership status mapping
- consent status mapping

## 10. Admin access

- primary organization admin
- backup admin
- who should receive billing/system notices
- support escalation contact

## 11. Launch checks

- test signup completed
- test successful payment completed
- test failed payment flow reviewed
- confirmation emails reviewed
- member record appears correctly in CRM
- embed or hosted page works on mobile and desktop

## 12. Handover

- admin has access to dashboard
- public signup URL shared
- embed instructions shared
- client knows how to update plans and view members
- launch date confirmed
